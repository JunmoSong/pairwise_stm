# Discovering Preference Structure using Randomized Paired Comparisons in Surveys: A Topic Modeling Approach

Replication data and code for the paper published in *Sociological Methods & Research*.

---

## Overview

This repository contains all data and R scripts necessary to replicate the analyses, figures, and tables reported in the paper. The study proposes a novel survey methodology that combines **Randomized Paired Comparisons (RPC)** with **topic modeling** (specifically Structural Topic Models) to uncover latent preference structures from survey respondents.

The empirical application examines Korean public perceptions of social problems, comparing two survey formats: a conventional matrix/Likert-scale format and the proposed RPC format.

## Data

**`data/social_problem.xlsx`** (Sheet 2) contains survey responses from a Korean sample (N = 920) collected in 2021. Respondents were randomly assigned to one of two conditions:

| Subsample | Format | N |
|---|---|---|
| Grid | Matrix/Likert scale (10 social problem items) | 302 |
| RPC | Randomized paired comparisons (5 pairs drawn from 10 items) | 618 |

Variables include respondent demographics (sex, age, region), political orientation, education, and survey responses.

## Scripts

Run the scripts **in order** from a working directory that contains the `data/` folder:

| Script | Description | Key Output |
|---|---|---|
| `01_data_preprocessing.R` | Imports raw data; splits into Grid and RPC subsamples; encodes pairwise responses as ordered-pair "documents" (`loser<winner`) | `data/df_sp_grid.csv`, `data/df_sp_rpc.csv` |
| `02_model_estimation.R` | Estimates STM (K=5), CTM, and LDA on the RPC data; computes overall selection rates | `data/model_objects.RData` |
| `03_main_figures_tables.R` | Generates Figures 4–7 and Tables 3–5 | `output/figures/`, `output/tables/` |
| `04_appendix_figures_tables.R` | Generates all appendix figures and tables | `output/figures/`, `output/tables/` |

> **Reproducibility note for Script 2:** The `searchK()` function involves random document holdouts not fully controlled by `set.seed()`. Diagnostic statistics (held-out likelihood, semantic coherence) may vary slightly across runs. The final STM with K = 5 is reproducible under `set.seed(2026)`.

## Requirements

All analyses were conducted in **R**. The following packages are required:

| Package | Version |
|---|---|
| `tidyverse` | 2.0.0 |
| `readxl` | 1.4.3 |
| `stm` | 1.3.7 |
| `topicmodels` | 0.2-17 |
| `tidytext` | 0.4.3 |
| `reshape2` | 1.4.4 |
| `igraph` | 2.1.4 |
| `ggraph` | 2.2.1 |

Install all packages at once:

```r
install.packages(c("tidyverse", "readxl", "stm", "topicmodels",
                   "tidytext", "reshape2", "igraph", "ggraph"))
```
